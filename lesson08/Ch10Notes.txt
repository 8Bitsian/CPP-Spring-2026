=== CHARCTER TESTING ===
CONCEPT: The C++ library provides several functions for testing characters. To use these functiosn you must include the <cctype> header file

The C++ library provides several functions that allow you to test the value of a chaacter.
These functions test a single char argument and return either true or false.

EX. The following program segment uses the isupper() function to determine whether the character passed as an argument is an uppercase letter.
    If it is, then the function returns true. Otherwise, it returns false.

    char letter = 'a';
    if (isupper(letter))
       cout << "Letter is lowercase.\n";
    else
       cout << "Letter is uppercase.\n";

    Because the variable letter, in this example, contains a lowercase letter, isupper() returns false.
    The if statement will cause the message "Letter is lowercase." to be displayed.

The following are several character-testing functions. Each of these is prototypes in the <cctype> header file:
- isalpha: Returns true (a nonzero number) if the argument is a letter of the alphabet. Returns false (0) if the argument is not a letter.
- isalnum: Returns true (a nonzero number) if the argument is a letter of the alphabet or a digit. Otherwise returns false (0).
- isdigit: Returns true (a nonzero number) if the argument is a letter of the alphabet. Returns false (0) if the argument is not a letter.
- islower: Returns true (a nonzero number) if the argument is a letter of the alphabet. Returns false (0) if the argument is not a letter.
- isprint: Returns true (a nonzero number) if the argument is a letter of the alphabet. Returns false (0) if the argument is not a letter.
- ispunct: Returns true (a nonzero number) if the argument is a letter of the alphabet. Returns false (0) if the argument is not a letter.
- isupper: Returns true (a nonzero number) if the argument is a letter of the alphabet. Returns false (0) if the argument is not a letter.

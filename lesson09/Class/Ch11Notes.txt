11.1 ABSTRACT DATA TYPES
CONCEPT: Abstract Data Types (ADTs) are data types created by the programmer.
ADTs have their own range (or domain)of data and their own sets of operations
that may be performed on them.

The term abstract data type (ADT) is significant in object-oriented programming (OOP).

An abstraction is a general model of something. It is a definition that includes only
the general characteristics of an object.

C++ has several primitive data types (PDT), or data types that are defined as a basic
part of the language, as shown below:

EX. bool, char, int, float, double

The additional long keyword increases the range and the unsigned keyword makes everything positive.

A data type defines what values a variable may hold. Each type listed above has its own
range of values. Data types also define what values a variable may not hold. In addition,
data types also define the operations that may be performed on a value. The previously
mentioned PDTs allow the following mathemetical and relational operations to be used on them:

EX. +, -, *, /, >, <, >=, <=, ==, !=

Only integer data types, however, with the modulus operator (%).

An abstract data type (ADT) is a data type created by the programmer and is composed of one
or more primitive data types. The programmer decides what values are acceptable for the data
type, as well as what operations may be performed on the data type. In many cases, the
programmer deisgns their own specialized operations.

In these notes you will learn how to combine variables of primitive data types to form your
own data structures, or ADTs.

11.12 ENUMERATED DATA TYPES
CONCEPT: An enumerated data type is a programmer-defiend data type. It consists of values known
as enumerators, which represent integer constants.

Using the enum key word, you can create your own data type and specific the values that belong to that type.

EX. enum Day { MONDAY, TUESDAY, WEDNESDAY, THRUSDAY, FRIDAY, SATURDAY, SUNDAY };

An enumerated type declaration begins with the key word enum, followed by the name of the type,
followed by a list of identifiers inside braces, and is terminated with a semicolon (;).
Here is the general format of an enumerated type declaration:

EX. enum TypeName { enumerators... };

NOTE: The enumerators are not enclosed in quotation marks; Therefore, they are not strings.
Enumerators must be legal C++ identifiers.

Once you have created an enumerated data type in your program, you can define variables of that type.
